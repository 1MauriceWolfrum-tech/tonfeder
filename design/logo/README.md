# Tonfeder · Logo

| Datei | Verwendung |
|---|---|
| `tonfeder-logo-dunkel.svg` | Logo auf dunklem Grund (Website, Präsentationen) |
| `tonfeder-logo-hell.svg` | Logo auf hellem Grund (Briefe, Dokumente, AVV) |
| `tonfeder-zeichen.svg` | Nur das Zeichen (App-Symbol, Social Media) |
| `favicon.svg` | Browser-Tab |
| `konzept-b-feder.svg`, `konzept-c-t-welle.svg` | Alternativen, nicht gewählt |

**Idee:** Ein Text-Cursor (I-Balken), dessen Schaft aus Pegelbalken besteht: Sprache wird zu Text am Cursor.

**Raster:** Zeichen auf 64 × 64, Ecken 3. Schriftzug aus 3er-Strichen mit eckigen Enden auf einem eigenen Raster (x-Höhe 12, Oberlänge 18). Keine Schriftart nötig, alles sind Pfade.

**Farben:** Lime `#a3e635`, Tinte `#0a0f0b`, Hell `#e8f0e9`, Lime für hellen Grund `#4d7c0f`.

**Vor dem Einsatz:** Markenrecherche (DPMA, EUIPO, Klassen 9 und 42). Für Druck und App-Icons PNGs in 16, 32, 64, 128, 256, 512 und 1024 px aus `tonfeder-zeichen.svg` erzeugen.
