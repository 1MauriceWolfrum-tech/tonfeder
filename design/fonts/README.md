# Schriften

Geist und Geist Mono, lateinischer Teilsatz, als WOFF2 von Google Fonts geladen und in `tonfeder-landingpage.html` als base64 eingebettet. So lädt die Seite keine Schriften von Drittanbietern nach.

- `geist-latin.woff2` – Geist, variabel 300–800
- `geist-mono-latin.woff2` – Geist Mono, variabel 400–600

Lizenz: SIL Open Font License 1.1, siehe `OFL.txt` (aus https://github.com/vercel/geist-font).
